What it does

Ingest reports automatically

Upload DMARC aggregate reports manually, or connect an IMAP mailbox and let a background worker poll it on a schedule.

Dedupe by design

Reports are keyed on report ID, org, and domain — re-uploading or re-polling the same report is always a no-op.

A dashboard built on donuts

Pass/fail, disposition, SPF and DKIM results, top domains and source IPs — every metric gets its own chart, plus a real data table underneath.

Role-based access

Admins configure ingestion, domains, and users. Viewers get full read access to every report and every number behind the charts.

Self-hosted, one image

A single Docker image serves both the app and the ingestion worker — docker compose up and you're running.

Built on a modern stack

Next.js, PostgreSQL, Prisma, NextAuth — nothing exotic, easy to self-host and extend.
